# Protocollo di Avvio Sessione

Segui questi passi ogni volta che inizi a lavorare su questo repository.

## 1. Caricamento Contesto Git
- **Fork dell'utente (ToRvaLDz)**: `origin` (ramo principale: `origin/main`)
- **Repository originale (end-4)**: `upstream` (ramo principale: `upstream/main`)
- *Riferimento*: Consulta sempre `directives/git.md` per i comandi specifici.

## 2. Verifica Stato Corrente
Prima di procedere con nuove richieste:
1. Controlla il branch attuale: `git branch --show-current`
2. Controlla lo stato dei file: `git status`
3. Verifica la sincronizzazione con `upstream/main`.

## 3. Conformità Direttive
Per ogni task specifico (es. modifiche alla configurazione Hyprland o script di setup), controlla se esiste una direttiva dedicata in `directives/`.
